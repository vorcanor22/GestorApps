
# 📱 GestorApps

**GestorApps** es una aplicación ligera y nativa para Android diseñada para analizar, ordenar y consultar rápidamente el almacenamiento y los detalles técnicos de las aplicaciones instaladas en tu dispositivo.

## ✨ Características principales

- **Análisis detallado de almacenamiento:** Consulta el tamaño de la aplicación, los datos de usuario y la memoria caché.
- **Ordenación inteligente:** Organiza las aplicaciones por espacio ocupado o por orden alfabético (A-Z).
- **Ficha técnica completa:** Consulta el nombre del paquete, versión instalada, código de versión, fecha de instalación y última actualización.
- **Interfaz moderna y oscura:** Diseño con Jetpack Compose y Material Design 3.
- **Privacidad:** Funciona sin conexión a Internet y no recopila ni envía datos personales.

## 📥 Instalación y uso

1. Descarga el archivo `.apk` desde la sección **Releases** de este repositorio.
2. Abre el APK en tu dispositivo Android.
3. Autoriza la instalación si Android lo solicita.
4. Abre GestorApps y sigue las indicaciones para conceder acceso a las estadísticas de uso.

## 🛠️ Tecnologías utilizadas

- **Lenguaje:** Kotlin
- **Interfaz:** Jetpack Compose
- **Diseño:** Material Design 3
- **Información de aplicaciones:** PackageManager
- **Almacenamiento:** StorageStatsManager

## 🔒 Privacidad

GestorApps está diseñado para funcionar localmente en el dispositivo. No necesita conexión a Internet ni servidores externos.

## 📋 Requisitos

- Android compatible con las APIs utilizadas.
- Permiso especial de acceso a estadísticas de uso para consultar el almacenamiento.
